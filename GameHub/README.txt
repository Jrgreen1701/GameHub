GameHub v3.3 - Windows launcher dashboard

Build: double-click build_exe.bat with Python installed. Run dist\GameHub.exe.

Changes: CurseForge detection; bundled sharp locally rendered logo artwork for Epic Games, Riot Client, Battlestate Games, CurseForge; custom PNG logo chooser; retained anti-flicker tile behavior.

Logo artwork is original simplified vector-style artwork, not official brand assets. For exact official artwork, use Change logo to select a PNG.

CurseForge installation locations vary; if not detected, use Add launcher and select CurseForge.exe.

Requires Windows; build and GUI not tested on Windows.

Version 3.4: Right-click any launcher tile to rename it, change/reset its logo, or remove a custom launcher. The Change Logo sidebar button has been removed. Display names and custom logos persist in AppData.

Version 3.5: Blue GameHub app icon included in Windows executable and title bar. Rebuild with build_exe.bat; Windows shortcut icon caches may need refreshing.
